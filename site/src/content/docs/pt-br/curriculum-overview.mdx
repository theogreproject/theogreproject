Este é o **mapa do curso**. Ele foi projetado para ser prático:
cada módulo é uma linha de missões, e cada linha de missões termina com algo que você pode realmente usar na mesa de jogo.

<Aside type="note">
  Status dos módulos:
  <Badge text="No Ar" variant="success" /> pronto para o uso,
  <Badge text="Rascunho" variant="caution" /> funcional, mas ainda em desenvolvimento,
  <Badge text="Planejado" variant="note" /> chegando em breve.
</Aside>
