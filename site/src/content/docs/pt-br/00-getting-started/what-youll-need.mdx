Antes de falar de ferramentas, vamos fazer a coisa mais importante: relaxar.

Você **não** precisa de uma configuração perfeita para se tornar um MJ melhor. Você não precisa de um VTT sofisticado. Não precisa de um aplicativo para criar mundos. Não precisa comprar uma pilha de livros. Não precisa de dados especiais, um caderno especial ou um ritual sagrado sob a lua cheia.

(Embora, se você quiser arrumar essas coisas, tá tudo bem também. E, convenhamos, vivenciar um ritual de verdade sob a lua cheia pode ser exatamente o que você precisa para criar o gancho que faltava para a sua próxima aventura.)

O que você precisa é de uma forma de capturar ideias, uma forma de manter seu trabalho organizado e uma forma de voltar na semana seguinte e continuar. Só isso.

Esta página é propositalmente entediante, no melhor sentido. Ela existe para remover atrito, não para adicioná-lo.

## O mínimo absoluto

Se você tiver estas três coisas, já está de bom tamanho:

Primeiro, você precisa de **um lugar para escrever**. Pode ser um caderno, um app de notas, um arquivo de texto ou um documento na nuvem. O único requisito é que seja fácil de abrir e que você não se sinta “travado” por ele.

Segundo, você precisa de **um lugar para guardar os artefatos**. Este curso gera materiais pequenos e reutilizáveis. Se eles ficarem espalhados em apps aleatórios e capturas de tela, você vai perdê-los. Uma única pasta já resolve. Chame de “Ogre” e siga com a vida.

Terceiro, você precisa de **uma forma de testar**. O ideal é sua mesa real, mas também pode ser um jogo um-a-um, uma chamada rápida no Discord ou uma simulação solo. Vamos ensinar como testar sem precisar de um grupo perfeito.

Isso é o mínimo. Todo o resto é opcional.

<Aside type="note">
  Você consegue fazer este curso apenas com um celular e um app de notas. Não é o ideal, mas
  funciona.
</Aside>

## O Diário do Ogre (seu registro de prática)

Se houver uma coisa que eu recomendaria com carinho, é ter um **Diário do Ogre**.

Não porque escrever diário seja mágico, mas porque ele cria um ciclo simples de feedback. Depois de rodar algo (ou até mesmo depois de ler uma lição), você registra em poucas linhas o que aconteceu. É assim que experiência vira habilidade.

Seu diário pode ser um arquivo único, um documento ou uma pasta cheia de notas pequenas. Ele não precisa ser bonito. O único objetivo é: quando você voltar mais tarde, conseguir enxergar seu próprio progresso e notar padrões.

Uma boa entrada de diário é curta. Geralmente é só algo como o que você tentou, o que aconteceu e o que fazer diferente da próxima vez.

## Uma pequena caixa de ferramentas

Você não precisa de nenhuma das ferramentas abaixo para ter sucesso neste curso. Esta seção existe por um único motivo: para você olhar para eles e pensar “ah, é verdade! Existem opções”.

Além disso: ferramentas mudam. Preços mudam. Funcionalidades se reorganizam. Tudo bem. Pense nisso como uma lista inicial amigável, não como um cânone sagrado.

Vamos manter esta página atualizada conforme o curso cresce e passamos a citar novas ferramentas em lições futuras.

### Escrita e notas

Se você quiser que suas anotações sejam fáceis de encontrar depois, escolha um “lar” e fique com ele por um tempo.

- [Obsidian](https://obsidian.md/) — notas em markdown simples e rápidas; ótimo para wikis pessoais.
- [Notion](https://www.notion.com/) — documentos e bases de dados no mesmo lugar; ideal se você gosta de organização visual.
- [Google Docs](https://docs.google.com/) — o clássico: simples, compartilhável e difícil de quebrar.
- Uma pasta simples de arquivos `.doc` — honestamente subestimada. Entediante. Confiável. Aprovada pelo Ogre.

### Organização de campanha & mundo

Ajudam quando você quer que NPCs, locais e tramas parem de viver só na sua cabeça.

- [Kanka](https://kanka.io/) — gerenciador de campanhas com plano gratuito; ótimo para organizar pessoas, lugares e facções.
- [World Anvil](https://www.worldanvil.com/) — plataforma de worldbuilding com plano gratuito; boa se você gosta de artigos estruturados e páginas de lore.

### Mapas (batalha, masmorra, cidades, regiões)

Mapas são opcionais, mas clareza não é. Se mapas ajudam sua mesa, aqui vão alguns pontos de partida fáceis:

- [Dungeon Scrawl](https://www.dungeonscrawl.com/) — mapas de masmorra rápidos no navegador (perfeito para “preciso de um mapa em 10 minutos”).
- [Inkarnate](https://inkarnate.com/) — mapas bonitos com plano gratuito (limitado, mas suficiente para aprender e experimentar).
- [Gerador de Cidades do Watabou](https://watabou.itch.io/medieval-fantasy-city-generator) — layouts instantâneos de vilas e cidades para capturar tela e anotar.

### VTTs (mesas virtuais)

Se você joga online, provavelmente vai querer um desses. Se joga presencialmente, pode ignorar esta parte completamente.

- [Roll20](https://roll20.net/) — grande, popular, cheio de recursos e utilizável gratuitamente.
- [Owlbear Rodeo](https://www.owlbear.rodeo/) — leve e rápido; ótimo quando você só quer um mapa e tokens, sem muita configuração.

<Aside type="tip">
  Se você é iniciante em VTTs, comece pela ferramenta mais simples que resolve seu problema. Sempre
  dá para “evoluir” depois.
</Aside>

### Dados & ferramentas de mesa online

Se você joga online (ou de forma híbrida), isso pode facilitar a vida.

- [Discord](https://discord.com/) — texto, voz, vídeo e canais; o “hub de mesa” padrão de muitos grupos.
- [Avrae](https://avrae.io/) — bot de dados poderoso para Discord (especialmente útil se o grupo gosta de automação).
- [RollAdvantage Dice Roller](https://rolladvantage.com/diceroller/) — dados rápidos no navegador quando você não quer usar bot.

### Tokens, handouts e visuais

Às vezes, uma imagem faz mais do que cinco parágrafos.

- [Token Stamp 2](https://rolladvantage.com/tokenstamp/) — transforme qualquer imagem em um token limpo de VTT em segundos.
- [Canva](https://www.canva.com/) — handouts simples, cartões rápidos, “páginas de livro falsas”, placas, cartazes, resumos de sessão.
- [Excalidraw](https://excalidraw.com/) — desenhos simples estilo quadro branco; ótimo para diagramas rápidos e fluxogramas.

### Música & ambientação (tempero opcional)

Não é obrigatório, mas pode ser divertido. Mantenha simples.

- [Tabletop Audio](https://tabletopaudio.com/) — ótimas faixas de ambientação para sessões de RPG.
- [Syrinscape](https://syrinscape.com/) — paisagens sonoras bem poderosas (freemium-ish; vale testar para ver se combina com seu estilo).

## Livros e referências

Você não precisa ler uma biblioteca inteira para fazer este curso. Quando indicarmos referências, será porque elas são realmente úteis, não porque sejam “leitura obrigatória”.

Se você gosta de teoria de RPG, ótimo — vai ter tocas de coelho opcionais. Se não gosta, ainda assim dá para avançar por todo o curso usando apenas o conteúdo do site.

## Uma nota sobre “agnóstico de sistema”

Este curso busca ensinar habilidades que funcionam bem em vários sistemas. Isso significa que você não precisa de um conjunto específico de regras para começar.

Mas precisa de uma coisinha: disposição para traduzir procedimentos para a realidade da sua mesa. Se o seu sistema não rola iniciativa, você adapta as ferramentas de ritmo de combate. Se não usa mapas, adapta as ferramentas de clareza espacial. Se o sistema é focado em narrativa, as ideias continuam as mesmas: clareza, escolhas, consequências e impulso.

O curso vai ajudar você a fazer essa tradução sem parecer dever de casa.

<Aside type="tip">
  Se você estiver jogando um sistema agora, fique com ele enquanto aprende. Trocar de sistema no
  meio do aprendizado pode embaralhar o feedback.
</Aside>

## Tarefa

Nada para comprar. Nada para instalar.

Você pode navegar pela lista de ferramentas opcionais acima se quiser ideias, mas não é obrigatório.

Se quiser se preparar de forma gentil, faça uma coisa simples: decida onde seus artefatos vão morar. Crie uma pasta ou um documento. Dê um nome. Pronto.
