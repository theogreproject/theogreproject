O Projeto Ogre é organizado como um aprendizado prático.

## Tipos de Lições

- **Guias**: ajuda passo a passo para realizar uma tarefa específica.
- **Referência**: explicações concisas de como algo funciona.
- **Exercícios**: pequenas repetições para construir uma habilidade.
- **Projetos**: entregáveis maiores que você pode compartilhar ou executar em sua mesa.

## O que significa "recursos abertos"

Escrevemos lições originais, e depois linkamos a materiais **gratuitos** de alta qualidade como estudo complementar.
Livros e cursos pagos podem ser recomendados como recursos **opcionais**.

## O que você deve publicar (opcional)

Se quiser, você pode manter um portfólio público do seu trabalho:

- esboços de aventuras
- planos de sessão
- resumos de cenários
- kits de ferramentas para encontros

Compartilhar é opcional — aprender não é.
