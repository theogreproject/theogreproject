## What you’ll learn

This curriculum is **system-agnostic**: it focuses on skills that transfer across games (D&D, Pathfinder, Call of Cthulhu, OSR, indie TTRPGs, and beyond).

<CardGrid>
  <Card title="Player Foundations">
    Become a better player first: table etiquette, spotlight sharing, collaboration, character goals, and how to help your GM run great sessions.
  </Card>

  <Card title="GM 101">
    Run your first sessions with confidence: scene framing, rulings, pacing, descriptions, NPC play, encounters, and session structure.
  </Card>

  <Card title="Session Prep & Tools">
    Build a reusable prep workflow: notes that don’t bloat, strong hooks, improv scaffolding, and “just enough” structure to stay flexible.
  </Card>

  <Card title="Worldbuilding that Serves Play">
    Create worlds that generate adventure: factions, locations, frontiers, mysteries, and constraints — without writing a novel.
  </Card>

  <Card title="Adventure Design">
    Design one-shots and campaigns: nodes, clues, fail-forward, meaningful choices, and player-driven progression.
  </Card>

  <Card title="Publishing & Sharing">
    Turn your work into clean modules: formatting, editing checklists, playtest loops, and open-licensed publishing basics.
  </Card>
</CardGrid>

## How it works

The Ogre Project is built like a practical apprenticeship:

- **Lessons** explain a single concept clearly.
- **Exercises** train one skill at a time.
- **Projects** produce something you can actually use at the table.
- **Optional resources** link to great free material so you can go deeper.

:::tip
If you want TOP vibes: think “learn by doing,” but the output isn’t an app — it’s a **session**, an **adventure**, a **toolkit**, or a **world**.
:::

---

## What you’ll build

By progressing through the curriculum, you’ll assemble a personal GM portfolio such as:

- A **session-ready one-shot** (with hooks, scenes, and contingencies)
- A **GM prep template** you can reuse forever
- A **small starter region** (locations + factions + problems)
- A **node-based mystery** with clues and fail-forward paths
- A **short adventure module** formatted for sharing

---

## Who this is for

- You want to GM but don’t know where to start.
- You already GM and want a stronger method (prep, pacing, encounters, improvisation).
- You love worldbuilding but want it to create **playable** content.
- You’re building a community table and want consistent, teachable practices.
