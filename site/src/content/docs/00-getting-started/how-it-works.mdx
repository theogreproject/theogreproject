The Ogre Project is organized like a practical apprenticeship.

## Lesson types

- **Guides**: step-by-step help to accomplish a specific task.
- **Reference**: concise explanations of how something works.
- **Exercises**: small reps to build a skill.
- **Projects**: larger deliverables you can share or run at your table.

## What “open resources” means

We write original lessons, then link to high-quality **free** materials as supporting study.
Paid books and courses may be recommended as **optional** resources.

## What you should publish (optional)

If you want, you can keep a public portfolio of your work:
- adventure outlines
- session plans
- setting briefs
- encounter toolkits

Sharing is optional — learning is not.

:::note
This project is English-first. Portuguese content will be added progressively.
:::
