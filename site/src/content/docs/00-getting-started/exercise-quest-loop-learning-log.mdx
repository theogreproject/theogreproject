## Goal

Create a tiny weekly log entry that turns learning into real table progress.

## Timebox

- 10–15 minutes

## Rules (constraints)

- Keep it **one screen**.
- Use **bullets**, not paragraphs.
- Link the thing you shipped (or name the file).

<Aside type="tip">
If you didn’t ship anything this week, write what you will ship in the next 48 hours.
Small. Runnable. Real.
</Aside>

## Prompt

Write one entry with:

- **What I’m learning:** (1 line)
- **What I shipped:** (link or filename)
- **One thing I’ll try at the table:** (1 bullet)

## Deliverable

One Learning Log entry saved somewhere you can find later.

## Quick check

- [ ] It fits on one screen
- [ ] It contains a real shipped artifact (or a concrete plan to ship within 48h)
- [ ] “Future me” can use this without context
