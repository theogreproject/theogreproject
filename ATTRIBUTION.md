# Attribution & External Resources

This project curates and references free resources from the internet.
Whenever we embed, quote, or adapt third-party materials, we document it here.

## Rules of thumb
- Prefer linking instead of copying.
- If we copy/adapt anything, ensure the license permits it and add attribution.
