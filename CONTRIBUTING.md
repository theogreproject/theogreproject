# Contributing to The Ogre Project

Thanks for helping build a free, open curriculum for TTRPG Game Masters and Worldbuilders.

## Scope (MVP phase)
- Keep PRs small: ideally one lesson or one focused improvement per PR.
- Prefer clarity over cleverness. This is a teaching project.

## Content rules
- The website and curriculum are written in English first.
- Portuguese (pt-BR) translations are welcome but may lag behind.

## Licensing

## External resources
- Prefer linking to free resources.
- If you adapt or include third-party material, add an entry to ATTRIBUTION.md.
